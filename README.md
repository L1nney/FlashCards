# 🎮 Flashcards Gamer

Projeto desenvolvido para a disciplina de **Educação Digital**. Trata-se de uma aplicação web interativa de *flashcards* (cartões de estudo) com perguntas e respostas sobre o mundo dos jogos, sistema de placar e animação 3D.

## 🚀 Funcionalidades
* 🔄 Animação 3D ao clicar no cartão para ver a resposta.
* 🎯 Botões de "Acertei" e "Errei" que calculam o placar em tempo real.
* ⬅️➡️ Navegação simples entre os cartões.
* 🎨 Visual moderno em estilo *Dark Gamer*.

## 🛠️ Tecnologias Utilizadas
* **HTML5**: Estruturação da página.
* **CSS3**: Estilização, layout responsivo e animação 3D.
* **JavaScript**: Lógica de troca de cartões e contagem de pontos.
